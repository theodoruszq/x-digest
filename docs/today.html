Theo's explainer "What is a harness?": the layer that turns an LLM into an agent

@theo·♥Likes: 2.5k·Original·Oct 23, 00:16 UTC

By default, all an LLM can do is generate text. In order for a language model to do anything more, it needs tools …

In order for an LLM to actually do stuff, it needs: Tools that can do things (read_file, edit_file, bash, search etc); A special syntaxn. 语法格式 for calling those tools via text; A system that parsesv. 解析 the message to identify that syntax and run the code; A method to give the response from the tool back to the LLM; A list of tools available w/ descriptions of how to use them. That is the harnessn. 运行框架（包着模型、替它执行工具的那层系统）.

tl;dr - An agent is what happens when you combine a harness and an LLM.

💡 收藏 3,100，比点赞还多。这是一篇 X 长文。他的厨房比喻：模型是厨师，harness 是厨房，Claude Code、Codex 这类 App 是"界面 + harness"打包在一起；MCP 像是可以拿来参考的菜谱。Theo 是 T3 Code 的作者，文末有给自家课程和产品的推广。
