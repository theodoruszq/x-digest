Matt Pocock: for coding agents, "readability" really means "verifiability", so design modules that can be tested on their own

@mattpocockuk·♥Likes: 1.9k·Original·Nov 4, 12:12 UTC

We need to reconsider our priorsn. 先入为主的看法（这里指对"代码可读性"的既有观念） on code readability.

Humans, compared to agents, are pretty slow at understanding large quantities of text. … So 'readability' to agents really means 'verifiability'. How easy it is to mess about withv. 随手摆弄、试着跑一跑 that code to see it working.

The takeaways: … Instead, think about how easy it is to verify. Design your codebase so modules can be tested and verified independently. Feel free to sacrifice a bit of readability for performance. Cyclomatic complexityn. 圈复杂度：衡量代码分支多少的指标 and function size don't matter to agents

💡 观点很干脆：给 agent 用的代码库，重点是"能不能快速验证"（测试覆盖、模块能独立跑），而不是人读起来舒不舒服。这是他的经验判断，不是实验数据；他也承认人偶尔要能读懂代码。
