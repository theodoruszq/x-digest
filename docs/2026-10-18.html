Google Research open-sources Harness², which lets an agent improve its own harnessn. 外壳（模型外面那套提示词、工具、记忆等配置） task by task

@akshay_pachaar·♥Likes: 649·Original·Oct 18, 09:39 UTC

a harness is everything wrapped around the model, like the system prompt, tools, memory, skills, and subagents. today a person designs it once, and the agent runs every new task with that same fixed setup.

Harness² lets the agent refine that setup for each new task on its own, with the model weightsn. 权重（模型参数） left untouched.

on every task, the agent proposes edits to its harness, runs a few candidate versions, and composes a better harness by comparing how those runs behaved. because it learns from the differences between runs, it needs no correct answer or gradern. 评分器 for the task.
