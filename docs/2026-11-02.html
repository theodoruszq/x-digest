@alive_·♥Likes: 8.0k·Original·Nov 1, 14:39 UTC

Hard to overstatev. 夸大 how big of a deal this is.

tl;dr — ANY unpatchedadj. 未打补丁的 Linux server with even a single TCP port exposed to the internet (say for HTTP or SSH) and MPTCP active (default for many Go web servers) is vulnerable to complete takeover.

💡 据 X 新闻汇总：漏洞编号 CVE-2026-98432，评分 9.8，影响 4.4 以来的内核，无需登录就能拿到 root；上游 10 月中已修复，但 Ubuntu、Red Hat 等发行版补丁还没跟上，Anthropic 的研究员用 AI 写出了验证攻击代码。Shopify 的 Tobi 只说了一句"What a disaster"（♥4.7k）。levelsio 的建议（♥3.0k）：VPS 端口全部关掉，SSH 只走 Tailscale，网页流量走 Cloudflare Tunnel。有自己的服务器的话，今天就该检查一下。MPTCP 是"多路径 TCP"。
