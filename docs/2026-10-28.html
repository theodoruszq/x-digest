New paper: plain RAG over raw chat history often beats dedicated agent memory systems

@omarsar0·♥Likes: 268·Original·Oct 27, 15:11 UTC

They show that many dedicated memory systems score below naiveadj. 朴素的、最简单的 retrieval over the raw history on LongMemEval, PersonaMem, and MINT-Eval, while costing much more.

They split a memory system's value into two parts. Memory benefit counts questions it answers that RAG misses. Memory tax counts questions RAG answers that the memory system gets wrong.

Building memory rewrites the history. Some facts get dropped or distorted during extraction, and some survive but become harder to retrieve.

A simple fix helped. Retrieving from the raw history alongside memory and rerankingv. 重新排序（检索结果） both together reduced the tax.

The practical takeaway here is that before adding a memory layer to your agent, compare it with plain retrieval over the transcript on your own data.

💡 RAG 就是"先从资料里检索相关片段，再交给模型回答"。论文名《Memory Tax》。对自己搭 agent 的人很实用：别急着上复杂的记忆系统，先拿最朴素的"搜原始聊天记录"做基线对比。
