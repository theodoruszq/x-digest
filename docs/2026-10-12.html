…this gap in shared understanding of LLM capability is *widening*. It's now less "two groups of people speaking past each other" and more a sharp funneln. 漏斗.

- Napkin math粗略估算 somewhere around 6B people (~75% of the population) have barely come in contact with LLMs at all.

- Around 1-2B (~20%) are casual and infrequent users of free-tier ChatGPT-like products. This group sees derpyadj. 傻乎乎的 chatbots and treats them a bit like a better Google search, a writing aid…

- …Somewhere around 20M people (0.2%) see first-hand that large, complex projects that used to take them weeks/months can now be completed by agents with a prompt. Building apps, copying apps, translating apps, decompiling apps from binaries…

…The general public has mostly not interacted with these systems. When they have, it looks like a derpy chatbot. The majority of professionals still see only a modest upliftn. 提升. And a small slivern. 一小部分 of professionals are experiencing the vertigon. 眩晕感 of the curve going vertical. And it is all happening at the same time.

AnyPS5: an open-source project that ports PS5 games to run natively on PC

@RoundtableSpace·♥Likes: 42·Original·Oct 12, 00:15 UTC

AnyPS5 portsv. 移植 PS5 executablesn. 可执行程序 to run natively on Windows and Linux. Not an emulator. It's at ~28K stars and 2.4K forks.

* relinker → turns PS5 executables into native PC format

* libraries → PS5 system libraries rebuilt from scratch

* graphics → shadersn. 着色器（在显卡上运行的图形程序） recompiled to SPIR-V

* reality check → so far a small 2D game is shown at 60 fps

→ no emulation, no separate runtime → ships no firmware, keys or Sony code → pitched for preservation and interoperabilityn. 互通性

💡 项目地址 github.com/boykopovar/AnyPS5。模拟器是在 PC 上"假装"成一台 PS5；它则把游戏程序本身改写成 PC 程序。OC3D 等媒体报道它已实现 100% 的 PS5 GPU 着色器指令转换。目前只跑起来一个小 2D 游戏，离玩大作还很远。点赞不多，但 GitHub 星数说明热度很高，和 10/11 的 REA、ArtCraft 同属最近的逆向、重写开源热潮。
