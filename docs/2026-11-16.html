We package repeated workflows as skills all the time, but the agent still re-reads the skill and decides every step on every run, which costs tokens and time.

Devs just open-sourced Swamp, where your coding agent turns a repeated skill into a workflow that it builds once and runs again and again…

Swamp workflow: about 506K tokens, 3 agents, 6.6 minutes
