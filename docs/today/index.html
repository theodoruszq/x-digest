A jailbrokenadj. 越狱破解的 PS5 runs the 27B-parameter Qwen 3.8 model on its own GPU

@Pirat_Nation·♥Likes: 1.8k·Original·Oct 14, 18:01 UTC

A jailbroken PS5 is now being used to run a powerful AI model directly on the console.

A project called PS5LM has managed to run Qwen 3.8 27B … using the PS5's GPU.

The PS5 has only 16GB of memory, so the AI model needs heavy compressionn. 压缩（这里指量化） to fit, even with that limitation, it can generate around 21 tokens per second.

Smaller AI models are much faster. Tests reached around 61 tokens per second with Gemma 4 E4B and up to 124 tokens per second with Llama 3.2 3B.

During the test, the PS5's GPU was working at 100%, while the CPU was barely being used. The console used around 86W of power and reached about 54°C.

💡 每秒 21 个 token 大约就是正常阅读速度，等于把游戏机变成了一台本地 AI 服务器。Andrew Curran 转发："PS5 上能跑 Qwen 3.8-27B 了"（♥ 130）。
