A simple agent habit: when it goes in circles, keep only the best result and restart in a fresh session

@undefinedKi·♥Likes: 92·Original·Oct 30, 15:08 UTC

Your agent gets dumber the longer it works on a task. …

The agent gets anchoredadj. 被（先前结果）锚定、思路被框住 to its own past attempts. The more history it sees, the smaller its edits get.

The fix is to make it forget. Every so often, close the session, keep only the best result so far, and start a fresh session from it.

On the same budget, that beat a single agent by up to 39% and parallel agents by up to 15%.

To do it yourself: when your agent starts going in circles, ask it to save the best version and what it learned, then open a fresh session and give it only that.

💡 据 X 新闻汇总，出自伯克利和斯坦福研究者的一篇 arXiv 论文。点赞不多但马上能用：让 agent 把"目前最好版本 + 学到的东西"写进一个文件，再开新会话只喂这个文件。做笔记应用 Notion 早期的工程师 Chet Corcos 说（♥185）："This is such a good idea, I'm embarrassed I didn't think of it."

France's lower house votes, 11 to 10, to tax every gigabyte Netflix and YouTube send to French users

@unusual_whales·♥Likes: 7.4k·Original·Oct 30, 22:04 UTC

French lawmakers approved a tax of €0.055 (5.5 cents) for every gigabyte of data that companies like Netflix and YouTube send to French users. It's a tax on the companies, not users directly, but the cost could get passed on tov. 转嫁给 subscribers.
