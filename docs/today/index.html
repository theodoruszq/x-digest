@esrtweet·♥Likes: 1.2k·Original·Nov 8, 19:53 UTC

I have deliberately chosen to keep the way I interact with large language models extremely simple, even primitiveadj. 原始的. I don't get all tangled up in spawning subagents, accumulating skills, or trying to build a software factory that runs while I'm not there. …

I have yet to see any convincing evidence that this is losing me productivity.

Nous Research ships a Security plugin for Hermes Agent: maps the attack surface, splits review across subagents, confirms bugs with reproductions

@NousResearch·♥Likes: 975·Original·Nov 8, 18:47 UTC

Hermes Agent can now review your codebase for security bugs with the new official Security plugin by @mark_s.

Hermes first maps what an attacker could reach and which inputs it trusts. It splits the code across parallel subagents, checks every candidate finding against the code, and traces whether an attacker can actually exploitv. 利用（漏洞） it.

Turn on test confirmation and Hermes writes a small reproductionn. 复现用例 for each finding and runs it in a temporary copy of the repo. Each report records the evidence and the findings Hermes ruled out排除了, and exports to SARIF一种静态分析结果的标准格式 for your existing tools.

💡 开源 agent 的实用插件：重点是“先复现再报告”，减少 AI 安全审查常见的误报。
