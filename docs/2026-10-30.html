Santiago's agent tip: when a bug slips through, fix the process, not just the bug

@svpino·♥Likes: 118·Original·Oct 29, 12:34 UTC

Every time you find an issue that goes through your agentic review, ask the following:

• What specific check should have caught this bug?

• At what stage should that check have run?

• Why didn't the existing tests, rules, or instructions catch it?

Then: If it was a missing test, write one. If it was a missing review rule, add it. If the instructions were unclear, improve them. If the agent was missing context, provide it.

💡 很实用的习惯：每次 agent 出错，就补一个测试、一条审查规则或一句说明（比如写进 AGENTS.md），让同样的错以后被自动拦住。agent 写的代码越多，这种"修流程"越值钱。
