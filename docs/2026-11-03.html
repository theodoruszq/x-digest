levelsio had Claude Code decompile Battlefield 1942 into C, compile it to WebAssembly and run it in the browser with multiplayer

@levelsio·♥Likes: 836·Original·Nov 2, 21:55 UTC

I decompiled probably my favorite game ever: Battlefield 1942 and I put it on the web with multiplayer …

I tried it 6 months ago and essentially gave up but I tried it today again with Opus 5.5 asking "can you try port the BF1942 demo in this folder to web"

- it disassembledv. 反汇编（把机器码还原成汇编指令） the x86 raw machine code to find 57,000 x86 functions

- it translated each x86 function into a C function …

- it outputed 100,000 lines of C

- it then compiled that to WebAssemblyn. 能在浏览器里跑的二进制代码格式 with Emscripten

- there were 300x Windows and Direct3D functions used which we had to rewrite to WebGL 2 and OpenGL …

- then we had to build our own network stack so it could connect to our multiplayer server via WebSockets

I have no idea how it did any of this but it did it and it seems to work!

💡 玩的是免费的 shareware 试玩版（共享软件试玩版）。他说以前的 Quake、DOOM 移植有开源项目打底，这次什么都没有，半年前试过放弃了，换成 Opus 5.5 才跑通。后续一条帖子（♥180）算了账：整个过程约 100 万输出 token，按 API 价格约 100 美元，他每月 Claude 订阅也是 100 美元。
