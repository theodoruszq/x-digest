> so far this is working great. i tried this in the past and it wasn't as great. some details
> - we have long running sessions per project
> - opus is told to do all work in deepseek [[subagents|n. 子代理：被主 agent 派去干具体活的小 agent]]
> - be strict about scope when creating a task
> - ask for [[proof of work|n. 工作证明：能核验的产出，而不只是口头总结]] instead of a summary
> - do a one step review of the [[diff|n. 代码改动差异]] to make sure it's not totally off
> opus is amazing at this role
