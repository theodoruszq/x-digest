**MIT paper: coding agents mean 25x more code — but releases only +30%, and app usage didn't move** · [Original](https://x.com/thesupermannx/status/2124138507367281023) · ♥ 1.4k · 2026-11-21T13:50:59Z
> devs who started using autonomous agents wrote 25.5x more code. commits up 240%. repos touched up 80%. actual releases? +30%. …
> After adopting tools claude code, devs wrote 7x more lines and deleted 12.2x more. repos abandoned within 30 days went from 60% to 69%.
> … new apps launching across the app store, play, chrome web store, sourceforge - roughly doubled since early 2025. user engagement? didn't move. …
> writing code was never the real [[bottleneck|n. 瓶颈]]. shipping something [[coherent|adj. 完整连贯的]], reviewing it properly, building a thing anyone wanted - that was.
