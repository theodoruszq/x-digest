**3. Anthropic now tells companies to remove unneeded subagents: one agent with skills often wins** · [Original](https://x.com/cherry_mx_reds/status/2113969070118666670) · ♥ 1.9k · 2026-10-24T12:21:16Z
> Anthropic is now recommending that companies REMOVE unnecessary subagents from their AI systems.
> … a single agent equipped with skills can frequently outperform complex multi-agent systems, and one customer seeing roughly 2x faster execution.
> → Skills: Teach the agent HOW to do something… → Tools / MCP: Give the agent the ability to DO things… → Subagents: Use for parallel work, isolated context, or tasks a single agent struggles with.
> The interesting part is [[progressive disclosure|n. 渐进式披露（需要时才加载）]]. Instead of [[spawning|v. 生成、派生出]] specialized agents or stuffing everything into a giant prompt, one agent discovers and loads skills and tools as needed.
> As models have gotten smarter, improving agent architecture is becoming less about what you can add and more about what you can delete.
💡 这是 @cherry_mx_reds 对 Anthropic 新指南的总结，不是官方账号。据 X 新闻汇总，指南里还提到一个团队把 15 个 agent 合并成 1 个，多 agent 方案成本是单 agent 的 1.8–5.1 倍，质量却没明显提高。实用做法：把子 agent 的说明改写成 skill，把它的动作做成工具，再跑评测确认效果没掉。
