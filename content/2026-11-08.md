**13. The Hacker News: Claude Code’s “don’t ask again” can save passwords in a file that then shows up on GitHub** · [Original](https://x.com/TheHackersNews/status/2118960196987080801) · ♥ 329 · 2026-11-07T06:54:13Z
> Claude Code’s "Don't Ask Again" option can save passwords and API keys in [[plaintext|n. 明文]].
> Apiiro found 2,539 exposed secrets across 1,994 public GitHub repos, including database [[credentials|n. 凭证、账号密钥]], SSH logins, and cloud keys.
> Deleting files doesn’t erase Git history.
💡 点了 “Yes, and don't ask again” 后，完整命令（可能含密码）会写入项目里的 `.claude/settings.local.json`。Apiiro 在公开 GitHub 上找到 1,122 份含密钥的该文件；扩大到 git 历史和日志则是 1,994 个仓库、2,539 个密钥。它只写本机全局 git 排除，不会写入项目的 `.gitignore`。先轮换密钥，再从仓库和历史里删掉该文件。数字来自 Apiiro / The Hacker News，他们大多未验证密钥是否仍有效。
