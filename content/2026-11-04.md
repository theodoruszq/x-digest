**1. Lauren (poteto): adversarial AI code reviews are mostly a waste of tokens, so she cuts them from her pstack toolkit** · [Original](https://x.com/poteto/status/2117437607940681849) · ♥ 9.6k · 2026-11-03T02:04:00Z
> maybe a hot take but i now consider [[adversarial reviews|n. 对抗式评审：让一个 agent 专门挑另一个 agent 的毛病]] mostly a waste of tokens. far better to use those tokens on [[empirical|adj. 靠实际运行和实验验证的]] combined with [[formal verification|n. 形式化验证：用数学方法证明代码满足规格]]. i have updated pstack to use the interrogate skill less, and eventually i think i may remove it altogether
> i have found very little value with code review in the abstract, agents tend to just get lost in the [[nitpicks|n. 吹毛求疵的小问题]] and [[yagnis|n. YAGNI（You Aren't Gonna Need It）：为用不到的需求过度设计]]
💡 pstack 是她开源的一套编码 agent 工作流，这两天很多人在试。她的意思是：让 agent 互相"挑刺"很烧 token 又抓不到重点，不如多花在真跑测试和形式化验证上。这是她自己的经验判断，不是实验数据。
