**1. Patrick Collison adds an "improvements" box to his vibe-coded apps: type a wish, an agent builds it** · [Original](https://x.com/patrickc/status/2116636967517798672) · ♥ 1.8k · 2026-10-31T21:02:32Z
> I'm now building an "improvements" feature into all of my personal vibecoded applications: a freeform text input that's hooked up to an agent that [[yolo|不加审查、大胆地]] implements whatever is submitted.
> It's an interesting experience -- the [[activation energy barrier|启动门槛（原指化学"活化能"）]] to sanding any rough edge or implementing any new feature becomes extremely low. Someone else who uses one of the applications I created has already implemented 150 improvements over the course of a few days. This pattern feels like a new kind of tool -- liquid software? -- and every application that doesn't have this feature now has a slightly rigid and [[anachronistic|adj. 过时的、不合时代的]] flavor. …
> Now, it's not obvious to me how this pattern can or should scale. Does it become unmaintainable after a while? … How does collaborative software work in this model? Can software designed this way be secure and reliable?

**5. QwenPU: a tiny LLM running on a chip "compiled" inside another LLM's weights** · [Original](https://x.com/divagr1925/status/2116544960023687432) · ♥ 1.5k · 2026-10-31T14:56:56Z
> A CPU inside an LLM is one thing, but running another LLM inside an LLM would be taking things a bit too far, wouldn't it?
> Anyways, here's an LLM running inside an LLM : QwenPU, an LLM (@karpathy's stories260k) running on an NPU compiled inside Qwen 3.5-4B's weights.
💡 这是一个"套娃"式的怪实验。作者几天前做了 Qwenputer（♥5.9k）：把一个完整的 RISC-V CPU 编进 Qwen3.5-4B 的权重，用模型自己的层当内存，能在推理过程中跑 C 和 MicroPython。这次更进一步，在里面跑了 Karpathy 的一个超小故事模型。NPU 是专门跑神经网络的处理器。
