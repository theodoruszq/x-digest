**6. MIT researchers let an agent rewrite the optimizer's code while the network trains** · [Original](https://x.com/SimulatedAnneal/status/2112936831398375800) · ♥ 850 · 2026-10-21T15:59:31Z
> Current [[optimizers|n. 优化器（训练时决定参数怎么调的算法）]] are static during training. What if the optimizer could think and react while the network trains?
> We let an agent watch the training dynamics and rewrite the optimizer's source code as training goes: a reactive optimizer.
> In every language and image setting we tried that has no tuned recipe, it matches or beats the best recipe one can one-shot, and it guards against [[loss spikes|n. 损失突增（训练突然变差）]] and [[overfitting|n. 过拟合]] by itself.
