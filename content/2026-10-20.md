**4. Mitchell Hashimoto: Rex translates old API messages in about 35 microseconds** · [Original](https://x.com/mitchellh/status/2112286460309364845) · ♥ 549 · 2026-10-19T20:55:11Z
> The latest Rex preview release includes a very important subsystem I've been working on for weeks to enable full forwards+backwards API [[compatibility|n. 兼容性]] with clients and servers.
> Every API change is a rule on a JSON pointer (RFC 6901). For each message, we compile all the rules between your version and ours into a [[trie|n. 字典树（前缀树）]] keyed by JSON path tokens. This happens [[lazily|adv. 惰性地（用到时才算）]] since we don't want a full [[quadratic|adj. 平方级的]] explosion …
> Next, we wrote a custom [[recursive descent|n. 递归下降（一种解析方法）]] streaming JSON editor (forward-pass only). If a key doesn't match any subtree in the trie, we fast-path copy the full value onto the wire …
> Equal chains of changes are [[interned|v. 驻留（相同的只存一份、大家共用）]] to the same pointer, so when we broadcast an event to many old clients, we translate it once per distinct chain, not once per client.
> … an upgrade costs about 35 _microseconds_ on a 20KB JSON body.
💡 Mitchell 是 HashiCorp（Terraform）联合创始人、终端 Ghostty 的作者。Rex 是他正在做的项目，原帖没介绍它具体做什么，只说 Mac 测试又邀请了 1000 人，Linux 测试本周开始。值得学的是思路：把每次 API 改动写成一条"规则"，只改需要改的字段，其余原样复制，相同的改动链只算一次。注意他们现在才到第 4 版，1 万次修订是模拟出来的压力测试。

**8. OpenAI says its models now handle COBOL, the same day a viral post said LLMs can't** · [Original](https://x.com/OpenAI/status/2112310345863930168) · ♥ 3.9k · 2026-10-19T22:30:05Z
> Our latest model advances bring stronger capabilities for building and migrating software in [[low-resource|adj. 训练资料少的]] programming languages such as COBOL, Fortran, and Visual Basic.
> These languages power software that banks, governments, and businesses depend on. Progress here means understanding decades of business logic and helping developers [[modernize|v. 现代化改造]] those systems while preserving what works.
💡 同一天早些时候，@__d_1ggin 的一条帖子很火（♥6.4k）："Lets not forget that an LLM can write code so fast today only because of the trillions of lines of code that were written by hand and released as open source. Try writing COBOL, ALGOL, or Eiffel with an LLM, where the training corpus（训练语料）is minimal, and then tell me." 意思是 AI 写代码快，全靠人类开源的海量代码，换成资料少的老语言试试。OpenAI 这条正好回应：据转述，在让模型用 20 种语言各写一个兼容 SQLite 的数据库的测试里，GPT-6 Astra 平均通过 87.4%，COBOL 从 10.9% 涨到 72.1%。这是 OpenAI 自己的测试，未经独立验证。COBOL 是 1959 年的语言，至今跑着很多银行系统。
