**Anthropic rewrote its Messages API from Python to Rust — and used the live Python service to verify Claude agents' work** · [Original](https://x.com/AnthropicAI/status/2125627317263466739) · ♥ 14k · 2026-11-25T16:26:59Z
> We recently [[migrated|v. 迁移（把系统换到新技术上）]] our Messages API from Python to Rust.
> On our engineering blog, we share how we used the existing service to verify the new one, with teams of Claude agents tracking down and fixing differences between the two versions.
💡 博客要点：Claude 大约一周写出核心请求路径的第一版；难的是“怎么确认没改坏”。他们把线上 Python 版本当作“标准答案”，用真实流量对比两个版本的输出，发现差异就自动派 agent 去修。结果：每个请求 CPU 用量降约 70%，首个 token 的中位延迟降约 20%，全程不停服（[博客](https://www.anthropic.com/research/migrating-api-to-rust)）。核心思路 “generator–verifier gap（生成容易、验证难）” 对任何用 AI 重写老系统的人都值得借鉴。

**Stanford's "Plato's Key": one simple rotation lets one LLM use another LLM's internal representations — no training** · [Original](https://x.com/viviencheng__/status/2125631050319831474) · ♥ 6.0k · 2026-11-25T16:41:49Z
> 🗝️ Introducing Plato's Key. A single rotation lets independently trained LLMs use each other's [[representations|n. （模型内部的）表征]] as their own. No [[gradients|n. 梯度（这里指不需要再训练）]] required ✨
💡 [博客](https://hazyresearch.stanford.edu/blog/2026-11-25-platos-key)里的例子：问模型 A “德国的首都是”，把模型 B 在“France”处的内部状态旋转一下替换进去，A 就回答 “Paris”。在 8 个家族、12 个模型上，中位迁移准确率 41%；还能“唤醒”模型存着但答不出来的知识。支持“不同模型最终学到相似世界结构”的假说。
